Match format

Leagues differ, so check the age-group numbers against yours and change any of them below. Periods: 2 for halves, 4 for quarters. Changing the number of players on the field clears the game you're currently planning, since the positions change. The default formation is what every new game starts with; each quarter can use a different formation from the menu on the Plan tab. Goalkeepers: with "Switch at halftime", auto-fill gives GK 1 and GK 2 a half each; "taking turns" starts whoever has kept goal first in fewer games this season.

Roster

Tier and positions drive auto-fill only. An unset tier is treated neutrally until assigned. Set goalkeeper priority after assigning Goalie as a primary or secondary position. None of these labels are printed on anything a parent sees.
