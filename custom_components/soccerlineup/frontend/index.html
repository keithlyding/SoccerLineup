The downloaded JSON file contains your team setup, roster, player settings, attendance, current lineup, saved games, and goals. You can restore it in SoccerLineup on another browser or device, or after this browser's stored data has been cleared. Restoring replaces the SoccerLineup data currently stored in that browser.

Match format

Changing the number of players on the field clears the game you're currently planning, since the positions change.
